# . CLIP 是什么

CLIP 全称是：

> **Contrastive Language–Image Pre-training**

它通常包含两个编码器：

```
图片 → Image Encoder → 图片向量
文本 → Text Encoder  → 文本向量
```

关键在于：

> 图片编码器和文本编码器输出的向量，被训练到同一个可比较的共享空间中。

例如：

```
一张猫的图片
    ↓ Image Encoder
[0.21, 0.73, -0.18, ...]
```

```
文本：“一只坐在沙发上的猫”
    ↓ Text Encoder
[0.19, 0.76, -0.15, ...]
```

因为图片和文本描述相匹配，所以两个向量会比较接近。

而文本：

```
“一辆停在街边的汽车”
```

对应的向量则会离猫的图片向量更远。

CLIP 学习的主要关系是：

```
图片 ↔ 文本
```

而不仅仅是：

```
文本 ↔ 文本
```

# 4. CLIP 是怎么训练的

CLIP 会使用大量“图片—文字描述”配对数据。

假设一个训练批次中有三组数据：

```
图片 A：猫
文本 A：“一只猫坐在沙发上”

图片 B：汽车
文本 B：“一辆红色汽车”

图片 C：披萨
文本 C：“一张奶酪披萨”
```

模型希望：

```
图片 A 向量接近文本 A 向量
图片 B 向量接近文本 B 向量
图片 C 向量接近文本 C 向量
```

同时希望错误组合距离更远：

```
图片 A 远离“红色汽车”
图片 A 远离“奶酪披萨”
```

可以抽象成一个相似度矩阵：
||猫文本|汽车文本|披萨文本|
|---|---|---|---|
|猫图片|高|低|低|
|汽车图片|低|高|低|
|披萨图片|低|低|高|

这种训练方式叫 **对比学习（Contrastive Learning）**。

模型不是直接生成图片描述，而是学习：

> 哪段文字与哪张图片更加匹配。
