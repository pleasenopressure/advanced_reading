# Advanced Reading｜个人学习与阅读笔记

这是我的个人学习与阅读笔记库，记录我在人工智能、软件工程、财务知识等领域的学习过程。

我希望通过阅读、整理和关联不同主题，把零散的资料逐步转化为便于回顾的知识体系。仓库既包含概念解释和专题笔记，也包含阅读摘录、参考资料与工具模板。

## 学习主题

### 人工智能与大语言模型

围绕大模型应用的核心概念、架构和工程实践进行学习与整理：

- **RAG 与知识检索**：文档解析与切分、向量数据库、近似最近邻搜索、Advanced RAG、Modular RAG 和 GraphRAG。
- **AI Agent**：Agent Loop、任务规划、工具调用、记忆系统，以及 MCP 与 Function Calling。
- **大模型基础与应用**：KV Cache、上下文表示、结构化输出、参数高效微调等。
- **相关技术概念**：余弦相似度、Cross-Encoder、CLIP 和有限状态机等。

### 财务知识与通识阅读

通过书籍阅读、摘录与主题整理，学习个人财务和长期规划相关知识。目前涉及《富爸爸穷爸爸》等阅读材料，以及人生规划笔记。

## 仓库内容

- **专题笔记**：围绕具体技术或问题整理的 Markdown 文档。
- **阅读摘录与注释**：记录书籍中的重点内容和阅读过程。
- **学习资料**：用于辅助阅读和理解的文档与参考材料。
- **模板与工具**：学习过程中使用或整理的模板及辅助脚本。
